## Структура директории данных

```
data/
├── database.db              ← SQLite база (default: data.db в текущей директории)
├── sources/
│   ├── CRM/
│   │   ├── source.json      ← обязательный файл конфигурации источника
│   │   └── labels/          ← опционально: метаданные отдельных меток
│   │       ├── email/
│   │       │   └── config.json
│   │       └── phone/
│   │           └── config.json
│   └── ERP/
│       └── source.json
└── snapshots/               ← выгрузки состояния (не реализовано)
```

## source.json

Обязательные поля: `name`, `key_label`.

```json
{
  "name": "CRM",
  "key_label": "customer_id",
  "p": 0.9,
  "description": "CRM-система"
}
```

| Поле          | Тип    | Обязательно | Описание                                      |
|---------------|--------|-------------|-----------------------------------------------|
| `name`        | string | да          | Уникальное имя источника                      |
| `key_label`   | string | да          | Имя столбца-идентификатора сущности           |
| `p`           | float  | нет (0.5)   | Вес доверия источника, диапазон [0.0, 1.0]    |
| `description` | string | нет         | Произвольное описание                         |

---

## labels/\<name\>/config.json

Создавать не обязательно: метки, отсутствующие в `labels/`, регистрируются автоматически при первой загрузке с весом `p=0.5`.

```json
{
  "name": "email",
  "p": 0.8,
  "description": "Email адрес клиента"
}
```

| Поле          | Тип    | Обязательно | Описание                                    |
|---------------|--------|-------------|---------------------------------------------|
| `name`        | string | да          | Имя метки (совпадает с именем директории)   |
| `p`           | float  | нет (0.5)   | Вес доверия метки, диапазон [0.0, 1.0]      |
| `description` | string | нет         | Произвольное описание                       |

## Формат файла данных

Колоночный JSON — каждый ключ является именем столбца, значение — массив значений строк:

```json
{
  "customer_id": ["1",       "2",       "3"      ],
  "email":       ["a@b.com", "b@b.com", "c@b.com"],
  "phone":       ["+7001",   "+7002",   null     ]
}
```

- Столбец `key_label` обязателен, `null` в нём недопустим
- Остальные столбцы произвольны, `null` означает логическое удаление значения
- Не все столбцы обязаны присутствовать в каждом файле (частичные загрузки работают)
- Числовые значения (`int`, `float`) приводятся к строке автоматически

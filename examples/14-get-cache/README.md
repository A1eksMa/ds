# 14 — `ds get --cache`

Инкрементальная свёртка: без `--cache` каждый `ds get` пересчитывает весь срез заново,
даже если с прошлого вызова изменилось пару строк. `--cache FILE` хранит промежуточный
результат свёртки на источник и, если с ним не происходило ничего структурного
(`delete`/`archive`/`unarchive`/`mv`/`compact`), досчитывает на следующий вызов только
новые транзакции — но отдаёт **побайтово тот же** JSON, что обычный `ds get`.

## Запуск

```bash
bash run.sh /tmp/ex14
```

Выводит три выгрузки:

1. `ds get --dt 1704067200 --cache get-cache.json` — кэша ещё нет → полная пересборка
   (как обычный `ds get`), `get-cache.json` создаётся;
2. после загрузки второго батча — тот же вызов с тем же файлом кэша: источник не менялся
   структурно с первого вызова → досчитываются только новые транзакции;
3. `ds get --dt 1706745600` без `--cache` — для сравнения: **идентичен** предыдущему блоку.

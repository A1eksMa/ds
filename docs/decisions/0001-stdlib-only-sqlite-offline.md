# 0001. Только стандартная библиотека, SQLite, офлайн

- **Статус:** Принято
- **Дата:** 2025-11-01 (зафиксировано ретроспективно из требований проекта)

## Контекст

Целевая среда развёртывания — с фиксированной версией интерпретатора Python (`3.9.20`) и
строгими политиками безопасности, **запрещающими установку сторонних пакетов**. Нет доступа в
сеть, нельзя занимать порты.

## Решение

- Язык — Python `>= 3.9`, только **стандартная библиотека**. `pytest` — исключительно для
  разработки, не для рантайма.
- Хранилище — **SQLite 3** (`sqlite3` в stdlib): один файл, ноль администрирования, транзакции.
- CLI — `argparse`. Формат данных — JSON (`json`). **Не YAML** — `PyYAML` внешний.
- Приложение не открывает сетевых портов и не инициирует соединений.

## Альтернативы

- Pandas/NumPy для обработки, Airflow/Luigi для конвейеров, PostgreSQL как хранилище — всё
  отклонено требованием среды.
- YAML-конфиги (как в первоначальном `PROJECT_STRUCTURE.md`) — заменены на JSON, см.
  [`../reference/config-format.md`](../reference/config-format.md).

## Последствия

- Простое развёртывание: скопировать код + файл БД.
- Всё, что нужно, пишется руками на stdlib или не делается.
- Горячие пути проектируются с расчётом на будущее переписывание на C/CPython-расширения —
  простые типы, без «питонической магии».
- Однонодовость: это встраиваемое хранилище, не распределённая система (см.
  [`../explanation/constraints.md`](../explanation/constraints.md)).

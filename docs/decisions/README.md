# Журнал архитектурных решений (ADR)

Каждый файл — одно решение: **контекст → решение → последствия**, плюс статус. ADR не
редактируются по сути после принятия — если решение изменилось, добавляется новый ADR,
который его замещает (`supersedes 000X`).

Сырьё для многих ADR — прежний корневой `TODO.md` (развёрнутое обсуждение с аргументами и
контраргументами) и `releases/README.md` (что и когда реализовано).

## Шаблон

```markdown
# NNNN. Короткое название решения

- **Статус:** Предложено | Принято | Принято, реализовано (версия) | Заменено ADR-XXXX
- **Дата:** YYYY-MM-DD

## Контекст
Что за проблема, какие силы действуют, какие ограничения.

## Решение
Что именно решили. Одно предложение — суть, дальше детали.

## Альтернативы
Что рассматривали и почему отклонили.

## Последствия
Что становится проще, что сложнее, за чем теперь следить.
```

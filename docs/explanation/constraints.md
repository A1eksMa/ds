# Технические ограничения и почему они такие

## Стек

| Компонент | Выбор | Обоснование |
|---|---|---|
| Язык | Python `>= 3.9` (целевая среда — `3.9.20`) | Строгое требование среды развёртывания: фиксированная версия интерпретатора. |
| Хранилище | SQLite 3 | Один файл, ноль администрирования, есть в стандартной поставке Python (`sqlite3`), транзакции, достаточно для одной ноды. |
| CLI | `argparse` (stdlib) | Без внешних CLI-фреймворков. |
| Формат данных | JSON (stdlib `json`) | Вход и выход. Не YAML: `PyYAML` — внешняя зависимость. |
| Зависимости | **только стандартная библиотека** | См. ниже. `pytest` — только для разработки. |

## Запрет внешних зависимостей

Среда развёртывания — с фиксированной версией Python и строгими политиками безопасности,
**запрещающими установку сторонних пакетов**. Отсюда:

- Запрещены Pandas / NumPy, Airflow / Luigi, веб- и сетевые фреймворки.
- Всё, что нужно, пишется на stdlib или не делается.

ADR — [`../decisions/0001-stdlib-only-sqlite-offline.md`](../decisions/0001-stdlib-only-sqlite-offline.md).

## Офлайн, одна нода

- Приложение **не открывает сетевых портов** и не инициирует соединений.
- Это **встраиваемое однонодовое** хранилище (как сам SQLite), а не распределённая система.
  «Большие данные» здесь — про объём разреженных историзированных записей на одной машине,
  **не** про MPP / шардирование / кластер. Горизонтального масштабирования нет и не
  планируется.

## Совместимость с CPython-оптимизацией

Критичные по производительности участки в перспективе планируется переписать на C / как
расширения CPython. Поэтому алгоритмы обработки проектируются с оглядкой на типы данных,
совместимые с таким переписыванием (простые структуры, без «питонической магии» в горячих
путях).

## Архитектура портов

Ядро отделено от SQLite через `StoragePort` (Protocol) с двумя реализациями: `SQLiteAdapter`
(рабочая) и `InMemoryAdapter` (тесты гоняются на обеих для паритета). Это **внутренняя**
точка подмены движка хранения, а не пользовательский API расширения — `ds` не фреймворк
(см. [`overview.md`](overview.md)). Подробно — [`../reference/storage-port.md`](../reference/storage-port.md).

## Процесс: `main` без тестов

Ветка `main` содержит только стабильный релизный код без тестов; тесты и dev-инструменты
живут в ветке разработки. Детали — в `CONTRIBUTING.md`.

# Формат выгрузки `ds get` (как в коде)

> **Контракт.** Это интерфейс, на который завязываются потребители (поллер, `ds-webui`).
> Реализация — `src/service/get.py`. Схема БД остаётся приватной; потребители полагаются
> только на формат ниже.

## Документ на источник

`ds get` выдаёт по одному JSON-объекту на источник — в stdout (один источник) или
файлом `<Source>.json` (`--out DIR`).

```json
{
  "meta": {
    "name": "CRM",
    "key": "customer_id",
    "as_of": 1706745600.0,
    "generated_at": 1787997618.34,
    "gen_max_cnt": 8,
    "include_archive": false,
    "rows": 4,
    "labels": ["email", "phone"]
  },
  "data": [
    { "customer_id": "101", "email": "alice@example.com", "phone": "+7-900-000-0001" },
    { "customer_id": "102", "email": "bob.new@example.com", "phone": "+7-900-000-0002" },
    { "customer_id": "103", "email": "carol@example.com", "phone": null },
    { "customer_id": "104", "email": "dave@example.com" }
  ]
}
```

### `meta`

| Поле | Смысл |
|---|---|
| `name` | имя источника |
| `key` | имя ключевого показателя (`srcs.key_label`); `null`, если у источника он не задан |
| `as_of` | эффективный срез: `--dt`, иначе момент запуска (Unix, сек) |
| `generated_at` | время генерации документа (`time.time()` на момент вызова) |
| `gen_max_cnt` | максимальный `cnt` среди транзакций источника, попавших в срез (`as_of` + `include_archive`); `0`, если транзакций нет. Водяной знак для детекта устаревания на стороне потребителя |
| `include_archive` | учитывались ли заархивированные транзакции |
| `rows` | длина `data` |
| `labels` | отсортированный список показателей-колонок (выбранных `--lb`/пресетом, иначе все не-ключевые показатели источника) |

### `data`

Широкая таблица: **строка на `id`**, отсортированная по строковому значению ключа.
Ключи объекта строки — имя ключевого показателя + показатели, у которых есть значение для
этого `id`, в алфавитном порядке.

| В `data` | Значит |
|---|---|
| `"phone": "+7-900-000-0001"` | последняя по `(dt, cnt)` транзакция дала это значение |
| `"phone": null` | последняя операция для `(phone, id)` — `DELETE` |
| ключ `phone` **отсутствует** в строке | для пары `(phone, id)` не было ни одной транзакции в срезе — это **не** то же, что `null` |

Все значения — строки (типизация не входит в `ds`, см.
[`../explanation/data-model.md`](../explanation/data-model.md)).

## Правило свёртки

Level 1: для каждой пары `(показатель, id)` побеждает транзакция с наибольшим `(dt, cnt)`
(`src/service/get.py :: fold_source`). Обоснование —
[`../decisions/0006-fold-order-dt-cnt.md`](../decisions/0006-fold-order-dt-cnt.md),
концепция — [`../explanation/single-source-fold.md`](../explanation/single-source-fold.md).
Кросс-источникового разрешения по весам `p` (Level 2) `get` **не делает** — если один `id`
есть в нескольких источниках, это просто разные документы.

## Пресет

`--preset FILE` читает **только секцию `query`** (остальное, например `view`, игнорируется):

```json
{
  "name": "base",
  "query": {
    "as_of": null,
    "include_archive": false,
    "labels": ["email"],
    "sources": {
      "CRM": { "labels": ["email", "phone"] },
      "ERP": { "labels": ["price", "stock"] }
    }
  }
}
```

| Поле `query` | Смысл |
|---|---|
| `as_of` | срез; `null` → текущий момент. Перекрывается флагом `--dt`. |
| `include_archive` | как `--archive` (флаг может только добавить). |
| `sources` | объект `{имя: {labels: [...]}}` **или** массив имён. Определяет, какие источники выгружать. Перекрывается `--src`. |
| `labels` | список показателей для источников без своей записи в `sources`. Перекрывается `--lb` (и `--lb` тогда сбрасывает пер-источниковые списки). |

`as_of` в файле-документе всегда абсолютный timestamp, даже если в пресете было `null`.

## Чего `get` не делает

- **Не пишет манифест.** Индекс над набором файлов (`manifest.js` с per-source свежестью и
  текущим `cnt` из БД для детекта устаревания) собирает поллер/потребитель.
- **Не заворачивает в `.js`.** `ds get` отдаёт голый JSON. Обёртка
  `window.DS.sources["CRM"] = {...};` под `file://` — задача потребителя.
- **Не делает JOIN между источниками.** Каждый документ — один источник.
- Формат манифеста и `.js`-обёртки специфицирован на стороне потребителя —
  [`ds-webui/docs/contract.md`](https://github.com/A1eksMa/ds-webui/blob/main/docs/contract.md).
